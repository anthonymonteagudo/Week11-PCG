# Sources and reuse

Original class material: PCG graphs, graph instances, museum demonstrations, trail terrain and lesson explanations prepared for Prof. Anthony Monteagudo's Technical Art course. Learning references inform the concepts; paid tutorial projects, graphs, transcripts and downloaded course archives are not included.

- **Old West Learning**, Dekogon / Epic Games, [Fab listing](https://www.fab.com/listings/785da98f-3c56-4736-b898-826116d8f06f). Required meshes, materials and texture dependencies retain their original `/Game/Northwood` package paths and applicable source license. Student-copy texture resolution is reduced for distribution.
- **Forest/snow vegetation dependencies:** existing instructor TechArtGym environment assets and Week 9 surface textures retain their source ownership and licenses. Inclusion in a private class project does not assign a new open license to these assets.
- **Kloofendal 48d Partly Cloudy (Pure Sky)**, Greg Zaal and Jarod Guest, [Poly Haven](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky), [CC0](https://polyhaven.com/license). A photographic sky, not dynamic weather.
- **Ben Cloward**, [PCG video series starting point](https://www.youtube.com/watch?v=NZLtrWLNTes): point data, masks, spline boundaries, fences and overlap reasoning.
- **Brandon Vox**, instructor-provided Udemy PCG notes: graph organization, subgraphs, attributes and modular building concepts. Our native project targets UE 5.7.4; course downloads are not dependencies.
- **Anastasia Opara**, [Lake Houses](https://anopara.gumroad.com/l/ngKUJ): relationships, relative placement and connected assembly. Attributed lecture reference images are distinct from our original building example.
- **Epic Games**, [PCG documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine/procedural-content-generation-framework-in-unreal-engine).
- **SideFX**, [Houdini Engine for Unreal](https://www.sidefx.com/products/houdini-engine/plug-ins/unreal-plug-in/): optional instructor showcase. No Houdini software or license is needed to open the main student project.

The included lecture reader has [full references and visual credits](Slides/SOURCES.md), including the named GDC examples, procedural methods book, game-design articles, SideFX examples and open-source media notices. The [native demo gallery](Instructor/Demo-Gallery.html) contains actual class captures rather than generated Unreal interfaces.

This repository and the full student ZIP are private teaching distributions. Third-party assets are not relicensed under MIT or a blanket course license. Do not extract and publicly redistribute source assets or tutorial reference images. The private repository owner controls access.
